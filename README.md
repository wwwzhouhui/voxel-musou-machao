# 体素无双 · 锦马超传

浏览器体素无双游戏：马超枪挑潼关，迎战曹操。Three.js r186、纯 ES Modules、**无构建步骤**，`python3 -m http.server` 即可开玩。

> **在线游玩：https://voxel-musou-machao.vercel.app/**
> **仓库：https://github.com/wwwzhouhui/voxel-musou-machao**

> 蓝本对照：mike007jd/voxel-musou（Three.js r186 体素无双，赵云 vs 300 士兵）。
> 本项目为**同类型原创实现**：体素模型、数值、文案、关卡全部自己写，**没有复制原仓库代码**；
> 题材换成马超 / 孙策 / 周瑜 / 典韦，战役换成潼关之战（211 年）。

## 玩法

- **第一章 · 潼关之战**：先斩敌 60 人，引曹操亲临关前，击败曹操即获胜。友军庞德与两名西凉兵并肩作战。**本章固定在潼关峡谷。**
- **自由演武**：无尽波次，敌军越打越多，看看能坚持几波。**可在潼关峡谷或阳平关夜战两张图上玩。**
- **千人斩试炼**：限时 3 分钟，目标 240 斩（第四阶段平衡探针后由 300 下调），冲击极限。**可在两张图上玩。**

## 弓手与箭矢

敌方弓手（墨绿甲、绿缨、木弓，一眼可辨）：

- 射程 10–26 米：太近会后退，太远会靠近，射程内站定拉弓。
- 拉弓前摇约 0.75 秒，弓身发橙光——这是反制窗口：**冲上去砍一刀即可打断**，弓光熄灭、不射箭。
- 箭是真实抛射物：直线初速 26 米/秒 + 重力抛物线，开火时按落点补偿仰角；站着不动必中，跑动或闪避（无敌帧）可以躲开。
- 箭矢用 48 支对象池 + InstancedMesh 复用，不会每箭新建 Mesh；命中玩家扣 7 点血，友军庞德也会被射。
- 箭会被挡下：站在箭路上的友军会替玩家挡箭（身体格挡），所以别总躲在庞德身后——他也会倒下。
- 波次配比：每波弓手占 15%，随波次 +2%，上限 25%（第 6 波起封顶）；其余为士卒 / 长枪兵 / 精锐。

反制要点：看弓光 → 闪避或走位；近身弓手，它只会后退不会近战；优先清掉桥头、营门口的弓手。

## 剧情过场

- **潼关开场**（约 11 秒，4 句）：墨水黑场字幕 + 镜头扫过关墙与敌军，马超“父兄之仇，今日必报”、庞德请战、曹军压境。只在潼关之战播放，自由演武 / 试炼只有一行播报。
- **Boss 登场**（约 5 秒，2 句）：斩 60 触发曹操时先切过场，曹操策马入场（镜头推近）+ 两句对白、血条亮起，再开战；过场期间敌军 AI 与计时冻结，玩家不会被偷袭。
- **胜利结尾**（约 7 秒，3 句）：击败曹操后马超与庞德对白 + 战绩旁白，再进结算屏；**败北**也有一句台词（约 2.5 秒）再结算。
- 全部可跳过：任意键 / 点击 / Esc 立即跳过；地址栏加 `?skipintro=1` 直接跳开场。

## 坐骑

- 马匹停在出生点附近（小地图黄点），靠近按 **F** 上马 / 下马。马超配白马，孙策枣红、周瑜乌马、典韦黑骝，体素马全部 BoxGeometry 拼装（马身 / 马头 / 四腿 / 鬃毛 / 马鞍 / 缰绳）。
- 骑乘：移速 ×1.6，转向变钝（角速度上限），攻击范围 ×1.15；仍可普攻、蓄力、无双；**空格改为冲刺爆发**（0.5 秒 ×2.2，冷却 3 秒），不能跳跃；**Shift/L 改为马上短冲**（无敌帧保留）。
- 冲锋：持续移动 2 秒进入冲锋态，撞中小兵 25 伤击飞（每敌每轮只算一次），撞 Boss 同样有效；冲锋时有尘土特效与马蹄音效。
- 落马：单次受击 ≥20（如 Boss 冲锋 25.2）或被 Boss 冲锋撞中即落马；弓箭（7 伤）、普通小兵攻击不会落马。马留在原地，可再上。两张图都能用坐骑；坐骑不参与评级加分。

## 远程攻击（Q）

按 **Q** 发射远程，自动瞄准锁定目标（R 锁定优先），否则取射程内最近敌兵，再无目标则朝面朝方向；命中飘字、攒无双，骑乘时也能骑射（射程 ×0.85、散布 +0.05）。友军庞德不新增远程；敌方弓手 AI 不动。远程弹丸走独立对象池（32 支，与敌箭池 48 支分开，不互相抢池），火矢带橙色拖尾。

| 武将 | 远程 | 伤害 | 射程 | 冷却 | 弹道 / 特点 |
| --- | --- | --- | --- | --- | --- |
| 马超 | 投枪 | 28（×攻击倍率） | 26 米 | 2.2 秒 | 单发，银白，略带抛物线 |
| 孙策 | 飞矛 | 14 × 3 发 | 20 米 | 1.8 秒 | 扇形 3 发散布 0.22 |
| 周瑜 | 火矢 | 16（×攻击倍率） | 30 米 | 1.4 秒 | 落点灼烧 3 秒，每秒 6 伤，半径 2.2 米（每 0.5 秒一跳，每跳 3 伤） |
| 典韦 | 飞戟 | 40（×攻击倍率） | 14 米 | 2.8 秒 | 单发重伤，弹道最慢 |

- 伤害按武将攻击倍率结算（周瑜 0.9 → 火矢约 14 伤，典韦 1.25 → 飞戟 50 伤）；打中 Boss 计伤害（实测投枪 28 伤）；灼烧区最多同时 4 个。
- HUD 无双条下方显示远程状态（“火矢就绪 [Q]” / “火矢冷却 1.2s”）。冷却中按 Q 无反应、无惩罚。

## 霸体

每名武将出招时有霸体窗口，窗口内受击**不被打断、不硬直**，伤害照常扣但有减伤；窗口外受击照常硬直。霸体反馈：脚下金色光圈 + 屏幕“🛡 霸体”提示。无双期间全程免疫（等同霸体且更强）。霸体只在出招窗口内生效，不是全程。

| 武将 | 霸体窗口 | 减伤 |
| --- | --- | --- |
| 马超 | N5–N6 重枪连段后段 | 20% |
| 孙策 | C3–C6 蓄力冲锋段 | 25% |
| 周瑜 | C1–C6 羽扇施法段 | 15% |
| 典韦 | N6 与 C6 终结瞬间 | 40% |

受击保护：受击命中后有 **0.5 秒无敌帧**（长于硬直 0.28 秒），不会被多个敌人同帧连打锁死；硬直会取消待结算的出招（霸体除外）。

## 鼠标视角（指针锁定）

进入战斗后自动请求指针锁定：光标隐藏，**滑动鼠标直接转视角**（灵敏度 0.0028 弧度/像素，俯仰限幅 0.08–1.0，与旧拖拽一致）。键盘转向不受影响。

- **Esc** 退出锁定 → 自动暂停（锁定中浏览器会吞掉 Esc，所以暂停靠锁定状态变化触发，不是按键）；点“继续战斗”重新锁定。
- 切出窗口 / 失焦同样先丢锁定再暂停，进度不丢。
- 锁定失败时（无手势、刚退出冷却期内）会提示“点击画面可锁定视角”，点画面重试；未锁定时仍可用拖拽视角兜底。
- 标题画面、结算画面不锁定；触屏设备没有鼠标，不请求锁定。

## 自适应画质

- 默认“自动”：滚动监测真实帧率，低于 30 持续 3 秒降一档，高于 55 持续 8 秒升一档（升档比降档保守），最多升回高档。
- 档位（高 → 中 → 低 → 极低）：Bloom 开/开/关/关；后期开/开/开/关；像素比 2 / 1.5 / 1 / 1；阴影开/开/关/关；场上敌数上限 32 / 28 / 22 / 17；**MSAA 4x / 2x / 0 / 0；DoF 开/关/关/关**。
- 手动优先：标题界面画质按钮（自动 / 高 / 中 / 低）或 `?quality=high|medium|low` 固定档位，手动档永不自动变；手动按过 B/P 后，自适应不再改动后期开关。切换档位时 HUD 右上角短暂提示当前档位。
- SwiftShader 下约 4fps 是测试环境限制，游戏内时间比真实时间慢约 12–15 倍；帧率用真实时间 1 秒窗口计数（已修掉 rAF 时间戳虚报 165fps 的 Bug），真机上按真实帧率走；真机帧率待用户实测。

## 后期：Bloom / 像素风

自研轻量后期管线（`src/post.js`，原创实现，未复制原项目 post.js 的重型 shader 链）：

- 流程：场景 → 场景 RT → 亮部提取（阈值 0.55）→ 两轮可分离高斯模糊 → 合成（原色 + 泛光 + 暗角 + 轻微饱和提升，sRGB 编码输出）。
- 默认开启 Bloom（强度 0.55，火把、金饰、白甲会泛光，不糊不刺眼）；像素风默认关闭。
- 开关：标题界面按钮、战斗中按 **B** 开关 Bloom、按 **P** 开关像素风；URL `?post=off|bloom|pixel|on`。
- `?quality=low` 强制关闭后期并降像素比；HUD 是 DOM，不进后期，不受影响。
- 像素风：场景降到 1/3 分辨率、NearestFilter 放大，体素块感更强。
- **MSAA**：场景 RT 的 WebGL2 `samples` 参数（高档 4x / 中档 2x / 低档以下 0），在自研后期管线下直接生效——场景先以多采样 RT 渲染再进泛光/合成，抗锯齿作用于整个场景；SwiftShader 下实测 `rtScene.samples` 与档位一致（4/2/0），无控制台错误。
- **DoF（深度景深）**：真深度 DoF，非径向假模糊。场景 RT 挂 `DepthTexture`，合成时按线性深度与焦点距离算模糊强度（焦点 ±2 米内清晰，18 米外满模糊，强度 0.85，8 抽头）；焦点每帧跟随锁定目标距离，否则跟随相机到玩家距离（约 9.5 米，默认 12 米）。只在高档开；战斗中按 **O** 开关，标题界面有景深按钮，URL `?dof=on|off`、`?msaa=0|2|4` 可手动覆盖。HUD 不进 DoF。
- 降级保护：场景 RT 按“MSAA+深度贴图 → 仅 MSAA → 普通 RT”三级重建，某组合不受支持时自动降一级，实际生效值记在 `post.msaaEffective / post.dofEffective`，不谎报。修复记录：曾因 `depthTexture: undefined` 传参触发 three r186 setter 抛错导致后期整体回退直出，现已修复（见 PROGRESS.md 第四阶段）。
- 性能：SwiftShader 下不崩；真机帧率待用户实测（见 PROGRESS.md）。

## 运行

```bash
cd voxel-musou-machao
python3 -m http.server 8321
# 打开 http://127.0.0.1:8321/
```

URL 参数：

```
?char=machao|sunce|zhouyu|dianwei   # 初始武将（默认 machao）
?mode=tongguan|endless|trial        # 初始战役（默认 tongguan）
?map=tongguan|yangping              # 初始地图（默认 tongguan；潼关之战固定 tongguan）
?enemies=220                        # 敌军槽位 20–600（默认 220）
?quality=auto|high|medium|low       # 画质模式：默认 auto 自适应；low=手动极低档（关阴影、像素比 1、关闭后期）
?post=on|bloom|pixel|off            # 后期：默认 on=Bloom；pixel=Bloom+像素风；off=关闭
?skipintro=1                        # 跳过潼关开场过场
```

### 离线 / 无 CDN

Three.js 已**本地 vendor 化**（`vendor/three/three.module.js` + `three.core.js`，r186 MIT），
importmap 指向本地文件，**不需要联网**即可打开。如需改回 CDN，把 `index.html` 的 importmap 改为：

```json
{ "imports": {
  "three": "https://cdn.jsdelivr.net/npm/three@0.186.0/build/three.module.js",
  "three/addons/": "https://cdn.jsdelivr.net/npm/three@0.186.0/examples/jsm/"
} }
```

## 技术架构

```
index.html            入口 + 全部 HUD/界面 CSS（系统字体，无外部字体依赖）
src/main.js           启动器：URL 参数、选角/章节/地图界面接线
src/config.js         武将/敌军/Boss/关卡/地图/弓手平衡数值、评级、URL 解析
src/combat.js         纯逻辑连招状态机（N1-N6/C1-C6/闪避/无双，可 node 自检）
src/voxel.js          体素拼装：BoxGeometry 程序化武将/武器/旗帜，无外部模型
src/world.js          地图注册表：潼关峡谷 + 阳平关夜战，各自地形/碰撞/出生点
src/spawns.js         敌潮出生点纯逻辑：每图 8 点轮询 + 抖动 + 最小间距（可 node 自检）
src/enemies.js        士兵群：InstancedMesh 分部位渲染 + AI（追击/包围/前摇/击飞/弓手拉弓射箭）
src/arrows.js         弓手抛射物纯逻辑：抛物线瞄准、48 支对象池（可 node 自检）
src/post.js           轻量后期：亮部泛光 + 像素化 + 合成（sRGB 编码）
src/cutscene.js       剧情过场纯逻辑：4 段台词脚本 + 播放器（可 node 自检）
src/mount.js          坐骑纯逻辑：上马/冲锋/落马/冲刺状态机（可 node 自检）
src/adaptive.js       自适应画质纯逻辑：4 档 + 升降阈值（可 node 自检）
src/game.js           主游戏：固定 60Hz 模拟、波次、Boss AI、HUD、小地图、结算、过场/坐骑/自适应接入
src/audio.js          程序化 WebAudio 音效（挥砍/命中/无双/胜利/弓箭/上马/冲锋），无音频文件
tests/checks.mjs      Node 回归自检（连招/评级/配置/地图/弓手/箭矢/过场/坐骑/自适应）
tests/phase2.mjs      无头 E2E：阳平关 / 弓手 / 后期开关
tests/phase3.mjs      无头 E2E：剧情过场 / 坐骑 / 自适应画质
```

关键设计（与原项目思路一致，实现各自独立）：

- **固定 60Hz 模拟步长**，渲染与模拟分离；命中顿帧（hitstop）强化打击感。
- **InstancedMesh 分部位渲染**小兵（身体/头/腿/武器/盔缨各一个 InstancedMesh），
  默认 220 敌军槽位、场上最多约 32 人，低配可降质。
- **程序化体素角色**：全部 BoxGeometry 拼装，马超银甲红缨、孙策绿甲、周瑜羽扇、
  典韦双戟、曹操紫金甲各有可辨识配色与武器。
- **程序化 WebAudio 音效**：无外部音频文件；M 静音。
- **localStorage 存档**：各模式 × 武将最佳纪录（斩数/评级/日期）。
