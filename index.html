玩法：潼关之战先斩敌 60 人，引曹操现身并击败他即获胜；自由演武为无尽波次；千人斩试炼限时 3 分钟、目标 240 斩（第四阶段平衡探针后由 300 下调，见 README / PROGRESS）。
击杀可积攒无双槽；小兵有概率掉落包子，拾取回血 25 点；连击越高越容易打出高评级（S/A/B/C）。
Boss 出招前会全身闪红并弹出警告，看到警告立刻闪避！
弓手反制：弓手（墨绿甲、绿缨、木弓）会在 10–26 米外站定拉弓，弓身发橙光约 0.75 秒后射箭。 箭是抛物线，跑动 + 闪避（无敌帧）可以躲开；冲到弓手面前或一刀砍中，就能打断拉弓。弓手怕近身，不会扎堆。 每波弓手占 15–25%，波次越高越多。
地图：潼关峡谷（南北峡谷 + 关墙）；阳平关夜战（中央营寨、东侧河流木桥、西侧粮仓、南侧隘口）， 自由演武与千人斩可在两张图上玩，潼关之战固定用潼关图。
剧情过场：潼关开场、曹操登场、胜利结尾均有过场，任意键 / 点击 / Esc 跳过；地址栏加 ?skipintro=1 直接跳开场。 自由演武 / 试炼没有开场过场。
坐骑：马匹停在出生点附近（小地图黄点），靠近按 F 上马。骑乘移速 ×1.6、转向变钝、攻击范围 ×1.15； 持续移动 2 秒进入冲锋，撞中小兵 25 伤击飞（每敌每轮只算一次）；单次受击 ≥20 或被 Boss 冲锋撞中会落马，马留在原地可再上。
自适应画质：默认“自动”，帧率低于 30 持续 3 秒降一档、高于 55 持续 8 秒升一档 （高 → 中 → 低 → 极低：Bloom、像素比、阴影、后期、场上敌数上限依次下调）；标题界面可改手动高 / 中 / 低，手动档永不自动变。 高档开 4x MSAA 与深度景深，中档 2x MSAA，低档以下关闭；景深焦点跟随锁定目标 / 玩家，远景模糊、近处清晰。 ?msaa=0|2|4、?dof=on|off 可手动覆盖，战斗中按 O 开关景深。
远程攻击：按 Q 发射，按武将不同：马超投枪（28 伤、26 米、冷却 2.2 秒）、 孙策飞矛（3 发扇形、各 14 伤、20 米、1.8 秒）、周瑜火矢（16 伤、30 米、1.4 秒，落点灼烧 3 秒、每秒 6 伤、半径 2.2 米）、 典韦飞戟（40 伤、14 米、2.8 秒）。伤害按武将攻击倍率结算；骑乘时射程 ×0.85、散布变大；命中攒无双。
